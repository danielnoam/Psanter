# Middle C position

Both thumbs share middle C. The right hand covers C to G above it, the left
hand C down to F below it. The music moves between the two staves, so watch
which clef each note is in.

```abc practice: tempo=60 hands=both
X:1
T:Thumbs on middle C
M:4/4
L:1/4
Q:1/4=60
K:C
V:R clef=treble
V:L clef=bass
[V:R] !1!C D E D | C4 | z4 | z4 | E F G2 | C4 |]
[V:L] z4 | z4 | !1!C B, A, B, | C4 | z4 | z4 |]
```

Frère Jacques, in the right hand. The fast notes are eighths: two to a beat.

```abc practice: tempo=80 hands=right
X:2
T:Frere Jacques
M:4/4
L:1/4
Q:1/4=80
K:C
C D E C | C D E C | E F G2 | E F G2 | G/A/G/F/ E C | G/A/G/F/ E C | C G, C2 | C G, C2 |]
```
