# Minor scales

A minor uses the same notes as C major, starting on A: that's the
**natural minor**. Raise the seventh note (G to G♯) and you get the
**harmonic minor**, which leads strongly back home. Same fingering as C.

```abc practice: tempo=60 hands=right
X:1
T:A natural minor
M:4/4
L:1/8
Q:1/4=60
K:Am
!1!A, !2!B, !3!C !1!D !2!E !3!F !4!G !5!A | !4!G !3!F !2!E !1!D !3!C !2!B, !1!A,2 |]
```

```abc practice: tempo=60 hands=right
X:2
T:A harmonic minor
M:4/4
L:1/8
Q:1/4=60
K:Am
!1!A, !2!B, !3!C !1!D !2!E !3!F !4!^G !5!A | !4!^G !3!F !2!E !1!D !3!C !2!B, !1!A,2 |]
```
