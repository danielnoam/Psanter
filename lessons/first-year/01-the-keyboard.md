# The keyboard and middle C

The black keys come in groups of two and three. Every C is the white key
just left of a group of two. The C nearest the middle of the piano is
**middle C**: the yellow dot on the app's keyboard.

Play middle C with your right thumb, then the C an octave above with your
little finger stretched (or move the hand). Count four beats on each long
note.

```abc practice: tempo=70 hands=right
X:1
T:Finding the Cs
M:4/4
L:1/4
Q:1/4=70
K:C
!1!C C C C | c c c c | C2 c2 | C4 |]
```

Now the left hand: the C an octave below middle C, with the little finger.

```abc practice: tempo=70 hands=left
X:2
T:Left hand Cs
M:4/4
L:1/4
Q:1/4=70
K:C clef=bass
!5!C, C, C, C, | C C C C | C,2 C2 | C,4 |]
```
