# Whole, half and quarter notes

In 4/4 there are four beats in a bar. A **quarter note** (filled, with a
stem) is one beat, a **half note** (hollow, with a stem) two, a **whole
note** (hollow, no stem) all four.

These use flow mode and the metronome: the music keeps going, and timing
counts. Count out loud, "one two three four".

```abc practice: tempo=70 hands=right mode=flow metronome=true
X:1
T:Counting fours
M:4/4
L:1/4
Q:1/4=70
K:C
C C C C | C2 C2 | C4 | C C C2 | C2 C C | C4 |]
```

```abc practice: tempo=70 hands=right mode=flow metronome=true
X:2
T:Long and short
M:4/4
L:1/4
Q:1/4=70
K:C
E D C2 | E D C2 | D D E E | C4 |]
```
