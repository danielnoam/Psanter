# Broken chords

Play a chord's notes one after another instead of together and you get a
**broken chord**. Low, high, middle, high is the **Alberti bass**, the
left-hand pattern behind a lot of Mozart.

```abc practice: tempo=70 hands=left
X:1
T:Up and down the chord
M:4/4
L:1/8
Q:1/4=70
K:C clef=bass
C, E, G, E, C, E, G, E, | F, A, C A, F, A, C A, | G, B, D B, G, B, D B, | C,8 |]
```

```abc practice: tempo=70 hands=left
X:2
T:Alberti bass
M:4/4
L:1/8
Q:1/4=70
K:C clef=bass
C, G, E, G, C, G, E, G, | C, A, F, A, C, A, F, A, | B,, G, D, G, B,, G, D, G, | C, G, E, G, C,4 |]
```
