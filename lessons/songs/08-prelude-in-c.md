# Prelude in C

The first bars of Bach's Prelude in C (Book 1 of The Well-Tempered
Clavier). Every bar is one chord, broken up the same way: two notes in the
left hand, three in the right, twice in each half of the bar. Learn the
shape of each chord, not the notes one by one.
