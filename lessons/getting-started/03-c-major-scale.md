# C major scale

One octave, hands separately first. In the right hand the thumb tucks under
after E going up; coming down, finger 3 crosses over the thumb onto E.

```abc practice: tempo=60 hands=right loop=true
X:1
T:C major, right hand
M:4/4
L:1/4
Q:1/4=60
K:C
!1!C !2!D !3!E !1!F | !2!G !3!A !4!B !5!c | c B A G | F !3!E D C |]
```

In the left hand it's the other way round: finger 3 crosses over the thumb
going up, and the thumb tucks under going down.

```abc practice: tempo=60 hands=left loop=true
X:2
T:C major, left hand
M:4/4
L:1/4
Q:1/4=60
K:C clef=bass
!5!C, !4!D, !3!E, !2!F, | !1!G, !3!A, !2!B, !1!C | C B, A, G, | F, E, D, C, |]
```

## Hands together

The fingers don't line up between the hands, which is the hard part. Set
the speed low and use wait mode until it's clean.

```abc practice: tempo=50 hands=both
X:3
T:C major, hands together
M:4/4
L:1/4
Q:1/4=50
K:C
V:R clef=treble
V:L clef=bass
[V:R] C D E F | G A B c | c B A G | F E D C |]
[V:L] C, D, E, F, | G, A, B, C | C B, A, G, | F, E, D, C, |]
```
