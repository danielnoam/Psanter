# C position

Put your right thumb on middle C and let each finger rest on the next white
key: thumb (1) on C, then 2, 3, 4 and 5 up to G. The left hand mirrors it an
octave lower, little finger (5) on C.

Keep the wrists level and the fingers curved, as if holding a ball.

## Right hand

```abc practice: tempo=70 hands=right
X:1
T:Right hand, C position
M:4/4
L:1/4
Q:1/4=70
K:C
!1!C !2!D !3!E !4!F | !5!G F E D | C4 |]
```

## Left hand

```abc practice: tempo=70 hands=left
X:2
T:Left hand, C position
M:4/4
L:1/4
Q:1/4=70
K:C clef=bass
!5!C, !4!D, !3!E, !2!F, | !1!G, F, E, D, | C,4 |]
```

## Both hands

Same notes, both hands together. Start with the speed at 60% if it's new.

```abc practice: tempo=60 hands=both
X:3
T:Hands together
M:4/4
L:1/4
Q:1/4=60
K:C
V:R clef=treble
V:L clef=bass
[V:R] C D E F | G F E D | C4 |]
[V:L] C, D, E, F, | G, F, E, D, | C,4 |]
```
